# Box Workout V7
PWA personale per allenamento con manubri, tappetino e corpo libero.

## Pubblicazione GitHub Pages
Caricare **il contenuto** di questa cartella nella root del repository `box-workout` (branch `main`). GitHub Pages deve puntare a `main / root`.

## Immagini
Le immagini degli esercizi sono richiamate dal progetto Free Exercise DB e vengono memorizzate dalla service worker dopo il primo caricamento. Il database dichiara Unlicense/Public Domain nel repository sorgente. Verificare separatamente eventuali requisiti di licenza/provenienza prima di un uso commerciale.
